## 一、做了什么(按能力,产品语言)

**人设(够拟人的地基)**
- 用户自填的"脚手架框":名字 / 基调(资深幕僚·机灵搭档·温和陪伴 3 预设)/ 称呼 / 关系 / 习惯雷区 / 自由补充;**「试一句」即时听腔调**。
- 锁死的"反机械"规则(替你拍板 / 不复读 / 开场多变 / 会回扣 / 会示弱 / 简洁),用户调味改不坏。
- 设置页 → 人设面板。换引擎、换场景(对话 ↔ 简报)是同一个性格、同一种腔调。

**记忆(记得住你)**
- 三层:原始对话 / 每日纪要(日终自动写"今天发生了什么")/ 关于你(耐久事实)。
- **「关于你」面板**:看 / 改 / 删 / 加,标「你说的 vs 学到」。
- 注入对话时**直读 DB 真相源**(跨窗口即时新鲜);pinned 不被截断;推断来的事实带「(推断)」。
- 记忆卫生:过期失效、新覆旧、日终去重归并。

**主动(会找你)**
- 流水线:触发(会议将至 / ddl 临近 / 任务卡住 / 刚完成 / 心跳)→ **闸门**(打扰预算 / 静默 / 冷却 / 去重 / 优先级,确定性纯函数,防骚扰地板)→ **懂状态**(安全版:只从日程密度 / 完成率推"负荷"调语气,信号不足返回"未知"不瞎猜)→ 合成 → 投递 → 打点。
- **晨间简报续接昨天**;首日不冷场;app 没开会**补发**(过晌午 / 已活跃则不误补)。
- **别烦我** + 连续忽略**自动降频**;三档(关 / 温和 / 积极),**默认温和**;悬浮条对新简报有轻提示。

**多引擎(为"发给大家用")**
- 统一 EngineAdapter:DeepSeek API / Claude Code / Codex 可切;**无状态**(每轮由 app 注入完整上下文,不依赖引擎自身 session);工具走 MCP server(:42800)。
- 结构化任务(任务解析 / 排今日)钉死走 API(CLI 给不了 JSON mode)。

**隐私**
- 云端大脑会看到注入记忆的**明确披露** + **仅本地大脑**(选云端后端时不把记忆喂过去)+ **敏感不记** + 省电低频模式。

## 二、自检结果

- 每个任务都走了 **TDD + 多维对抗复审**(规格 / 代码质量 / 多窗口真相源铁律 / 纯函数可测性),有 blocking 修到干净再往下。
- 两道**全项目终审**都判 **"端到端成立、可交付"**:整套秘书真的串成一个环(无孤岛),铁律全程遵守(多窗口真相源、纯函数 + 时间注入、适配器无状态)。
- 过程中修掉的真 bug:① 改人设对话窗不生效(多窗口陈旧 store);② 点"别烦我"反而抢焦点;③ **CC/Codex 的 MCP 一直没真注入**(顺带修好了存在已久的 CLI 聊天 MCP 缺失)。
