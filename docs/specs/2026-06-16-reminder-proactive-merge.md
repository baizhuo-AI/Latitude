# 定时提醒 × 主动提醒 合并方案(全合)

- 日期:2026-06-16
- 状态:方案定稿(决策已拍),**待排期实施**
- 依赖:AI 秘书改造 Phase 0-4(`feature/ai-secretary`,已实现)
- 一句话:把老的"定时活动记录提醒"(`reminder.ts` 裸定时器)**升维成秘书主动引擎里的一个触发类型 `activity_capture`**,两套"定时打扰你"的系统收成一套。

## 决策记录(已拍,实施按此)
1. **全合**:活动记录降格/升维成主动引擎的触发类型,不保留独立定时器(否决"轻耦合")。
2. **策略开关**:`activity_capture` 有独立节奏档——`随秘书克制`(默认,忙时/别烦我不催)/ `按时硬提醒`(只认工作时段+别烦我,不被"忙"挡)。
3. **捕获方式**:秘书对话里问一句、用户回一句即记(主);保留一键"记一笔"快捷入口(兜底)。

## 背景
现有两套"app 定时打扰你"的系统并存:
- **老:`reminder.ts`** —— 工作时段内每隔 N 分钟弹 todo 浮窗 + 可选系统通知,催用户手动"记录活动"(写 `activity_log`,喂活动时间线)。裸定时器,不看用户忙不忙、不调用大脑。
- **新:主动引擎** —— 触发 → 闸门(预算/静默/冷却/去重/别烦我/负荷)→ 大脑合成 → 投递 → 打点。智能、带人设、读记忆。

两者重叠:工作时段、静默/别烦我(`pausedUntil` 已共享)、通知渠道、定时 tick。问题:配置填两遍、可能双重打扰、老提醒不认"别烦我/忙"。

## 目标
一套主动外联系统;活动记录从"机械弹窗手填"变成"秘书定期问候顺带把活儿记了"——一次打扰办三件事(记活动 + 喂秘书记忆 + 拟人交互);消除双重打扰与重复配置。

## 方案

### 统一模型
主动引擎新增触发类型 `activity_capture`,复用现有「触发 → 闸门 → 投递 → 打点」管线。`reminder.ts` 的独立 `setInterval` 退役,其工作时段/间隔的**纯函数判定**移植为该触发的 `shouldRun`。

### 活动捕获流程
```
activity_capture 触发(到间隔)
  → 闸门(尊重 别烦我/静默;忙时是否催由"策略档"决定)
  → 秘书在对话问:"过去这阵在忙啥?一句话我记下"(带人设腔调)
  → 用户回一句
  → 落两处:① activity_log(喂活动时间线,可选 generateOnce 抽成干净一条,保留 occurred_at)
            ② 提炼成记忆事实/纪要素材(喂秘书对你的了解)
  → 忽略 → 不记(同现状),计入 dismiss 降频
保留:一键"记一笔"快捷入口(不想聊的人直接填)
```

### 策略开关(解"规律性 vs 克制"张力)
活动记录要规律、秘书闸门要克制,二者冲突。`activity_capture` 给独立节奏:
- 自己的间隔(继承 `reminder.intervalMin`)。
- 档位:`随秘书克制`(默认)= 忙时/别烦我不催;`按时硬提醒` = 跳过"忙时"调制,但仍认别烦我+静默。

### 配置统一 + 迁移
- 设置页:`reminder` 的 间隔/工作时段/渠道 并进 `ProactiveSettings`,工作时段/静默/别烦我/预算只填一遍;活动记录作为其下子项(开关 + 间隔 + 策略档)。
- 迁移:老 `reminder.{enabled,intervalMin,channel,workStart,workEnd,pausedUntil}` 平滑映射;`pausedUntil` 本已共享。默认值进 `defaults()`。不丢配置。

## 风险点
| 类型 | 风险 | 缓解 |
|---|---|---|
| 实现 | `reminder.ts` 现成 work、有测试、有 todo 浮窗 UX,折进去有回归 | 保留其纯函数判定当 `shouldRun`,只把独立 `setInterval` 换成 scheduler 心跳;特征化测试锁现有行为 |
| 体验 | 时间追踪党嫌被克制掉、记漏 | `按时硬提醒`档让其自选 |
| 体验 | "对话回一句"对某些人比弹窗慢 | 保留一键快捷记录入口 |
| 项目 | 配置迁移丢老设置 | 迁移兜底 + 默认值进 defaults() |

## 方法(实施路径)
1. `triggers.ts` 加 `activity_capture` 候选类型,移植 reminder 的工作时段/间隔纯函数判定为 `shouldRun`。
2. `gateProactive` 支持该类型的策略档(随克制/硬提醒):硬提醒模式跳过"忙时"调制,仍认别烦我+静默。
3. `deliverProactive` 加"活动捕获"变体:对话问句 + 标记对话为 `activity_capture`;保留一键快捷记录入口。
4. **回写**:chatStore 检测到用户在 `activity_capture` 对话回复 → 写 `activity_log`(可选 generateOnce 抽干净)+ 顺带提炼记忆。
5. 配置:`ProactiveSettings` 并入活动记录子项;`reminder` 配置迁移;拆 `reminder.ts` 独立 `setInterval`(逻辑并入 scheduler 心跳),保留纯函数。
6. 验收:活动提醒尊重别烦我/静默;按所选档决定忙时催不催;回复落进活动时间线 + 喂记忆;不再与秘书消息双重打扰;老配置生效;现有活动时间线功能不坏。

## 协同
与"会议提醒可能漏"(心跳间隔 90min > 会议窗 30min)共用触发/心跳基建,建议同一批实施时一并调整心跳/事件级巡检节奏。
