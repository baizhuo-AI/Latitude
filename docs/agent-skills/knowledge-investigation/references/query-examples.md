# 查询调整示例

均为假设材料；工具名称与字段以运行时契约为准。

## 下周是否旅游

先看是否已有相关安排、本人说明的条件，以及会影响建议的缺口。已有足够背景时无需搜索完整人格。

如果“旅游偏好”没有命中：检查返回是否只搜索 claim/preference，是否还没搜索经历。如果是，转向出游、休息安排、换环境等实际表述及有关决策和结果。不是继续索取一个空查询的第二页。

若找到一次短途出游，摘要只说“回来很累”：先回读对应交流，确认是交通、活动密度还是其他原因。这里再搜索更多“旅行”条目的价值可能低于展开这条具体经历。

如果原文表明劳累主要来自赶行程，可以查其他安排密度不同的经历，判断能否形成条件性建议。另一个摘要若来自同一次出游，不算独立对照。若资料仅覆盖一次体验，保留该范围，不必继续寻找一个确定人格标签。

仍需判断下周是否与真实承诺冲突时，查询当周相关事项。过去的旅行体验不能代替当前时间安排。历史结果已足够，而当周约束未知时，应说明后者，不用更多历史材料掩盖这个缺口。

## 要求 AI 交付证据意味着什么

“重视验收”的旧认识不是调查终点。回读触发批评的任务与实际结果，区分工具没完成、职业责任、产品测试以及跨情境偏好等解释。

如果首页都是同一个失败任务的片段，继续翻页不一定增加区分力。可转向其他独立任务，或本人对那批交互的说明。发现直接纠正时，先核对其适用批次，再判断是否需要修订原解释。

## 最近在忙什么

按时间与进行中的对象找进展。第一页若含多个相关事项而仍有未覆盖项目，可继续分页；若结果都是同一个项目的重复摘要，转查其他对象或调整去重范围。

能概括主要事项及已知进展时可以结束，说明缺少结果的部分。不为凑齐一个全库清单而无限展开，也不声称导航页之外没有活动。

## 失败与无进展

同一查询重试只适用于可恢复错误或底层索引确实更新；语义空结果需要考虑查询调整。没有访问权限与来源自然到期不会因换查询词而恢复，不尝试扩大权限范围。

不能把“已经读了很多”作为完成理由；也不能把“还有一页”作为继续理由。判断的是剩余材料是否有望改变当前答案。
