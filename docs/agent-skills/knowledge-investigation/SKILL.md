# 按证据缺口调整读取

先确定本次需要知道什么、哪项未知会改变答案。导航和已有上下文够用时直接回答；需要查证时，选择最有希望补足该缺口的一条路径。

以运行时实际提供的查询、关系读取和原文读取工具为准。分页游标只延续原查询；改变查询对象、条件或方向时重新查询。工具缺少覆盖信息时把范围记为未知，不假设已经查全。

## 如何选择下一步

| 当前观察 | 可考虑的读取动作 |
|---|---|
| 结果相关，仍缺同一集合中的条目 | 继续分页；若已定位关键条目，也可先读详情 |
| 返回为空，可能是表述不同 | 改用原话、别名、具体行为或场景词，拆开过多的联合条件 |
| 问的是偏好，库里可能只有经历 | 从有关事件、选择、目标和反馈查起，不要求先存在偏好标签 |
| 找到相关对象，但理由或结果缺失 | 沿其背景、依据、决策、行动、结果或修订关系查找 |
| 命中同名对象、旧时间或其他主体 | 收窄主体、对象身份或时间；需要旧经历时明确查询历史，不混为当前状态 |
| 摘要可能遗漏因果、否定、说话者或条件 | 回读对应原文及必要的前后交互 |
| 存在纠正、冲突或多个解释 | 查纠正与反例；优先找能区分解释的独立事件，而不是增加同方向例子 |
| 命中反复是同一批内容 | 查看工具报告的覆盖与共同来源；换路径、收窄问题，或结束当前搜索 |
| 索引尚未覆盖、来源不可用或工具报错 | 区分覆盖缺口、访问限制和可重试错误；不把这些情况写成没有该信息 |

这些动作不是依次执行的清单。每次读取服务一个具体缺口；结果若改变了问题理解，就调整问题本身。转向应有新线索或不同的覆盖范围，避免只换同义词却重复读取同一集合。

## 怎样判断停止

比较读前与读后：是否增加独立依据、解决关键缺口，或改变了候选解释与适用范围。重复命中、重复概括和同源派生不是新的支持。

材料足以支持当前所需的回答，可以在仍有游标时结束。重要缺口未解决、但剩余可用路径无望改善判断时，给出范围明确的回答并保留未知。只有用户能提供的关键信息，可以在合适时询问；普通缺口无需逐项打断用户。预算提醒促使选择更有价值的路径或收束，不证明证据已经充分。

留下简短的已查范围、未解缺口和停止依据，不输出逐步内部推理。后台工作可以以待补结束，并注明什么新材料或状态变化值得重看；资料没变化不重复调查。

需要对照具体走法时，读取 [查询调整示例](references/query-examples.md)。示例提供判断依据，不规定调用次数。
