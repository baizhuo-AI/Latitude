# 理解当次认知与行为

围绕实际问题选择方法。先找本人说过的理由、预期、约束及有关经历；明确表达的当次动机和认知可以直接结构化，不必等待跨情境重复。模型提出的解释单独标记，写清依据和适用范围。

需要方法帮助查背景、比较解释或理解变化时，按下面的入口读取相关部分：

- 本人如何理解问题、为何在意、怎样取舍：读 [情境、动机与选择](references/context-motivation-choice.md)。
- 为什么没有行动、怎样解释结果、到底改变了什么：读 [行动、归因与变化](references/action-attribution-change.md)。

新矛盾、重要反馈、少见且代价明显的选择，以及多个经历间的新联系，都可能值得进一步理解；这些是线索，不是封闭的触发清单。没有新认识时可不变；不为使用方法而制造问题。

输出有用的目标、判断、选择、结果和关系，附对应来源及范围；不是输出六个模块的完成表。方法能帮助提出解释，但不能作为关于用户的新证据。单次经历可以长期保留为经历，不自动成为长期特质。

在知识治理任务中，将产物交回 [knowledge-governance](../knowledge-governance/SKILL.md) 所描述的新旧比较、提交与回执流程；同一执行者可直接继续，无需另起 Agent。在线只为本次回答分析时，不默认将全部产物入库。分析完成与写入成功分别报告。
