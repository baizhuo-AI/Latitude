# 行动、归因与变化

## 行为实施

适合解释选择为何没有变成行动、怎样推进、哪些条件有帮助。借鉴 COM-B，检查实际能力、环境机会和动机，包含有意调节与习惯性触发。

先核对意愿、决定、开始、持续与结果分别有哪些材料。资料没到、没有可用时间或目标已经变化，不能统一解释成缺乏自律。

可形成行动状态、条件与阻碍及有关假设；协助建议与实际执行分开。[原始参考](https://link.springer.com/article/10.1186/1748-5908-6-42)

## 归因与竞争解释

适合本人解释成功失败、或维度需要区分行为原因时。借鉴 Weiner 的归因视角，了解本人把原因看作什么、是否稳定、是否可控；借鉴 Kelley 的比较视角，查其他条件下的表现和替代解释。

“本人说因为能力不足”是他的归因，不直接证明实际原因。个人因素与情境因素可以共同起作用；找能够区分解释的材料，而不是堆同方向例子。

分别形成本人归因和系统假设，保留支持、反例和缺口。[Weiner 原始参考](https://www.researchgate.net/publication/19257755_An_Attributional_Theory_of_Achievement_Motivation_and_Emotion)、[Kelley 原始参考](https://www.researchgate.net/publication/235413106_The_processes_of_causal_attribution)

## 反馈与变化

适合实际结果偏离预期、本人调整做法或看法时。借鉴自我调节学习的循环，连接事前判断、行动、结果、本人解释及后续调整；需要时进一步看目标和基本前提是否改变。

分清人的认知变化、策略变化、环境变化、系统纠错与新材料补足覆盖。打算改变不等于已经实践；单次结果不证明普遍规律。

可形成 outcome、带时间的认识修订及其依据。旧判断的有效范围和后来获知的时间分开，便于历史回看。[原始参考](https://doi.org/10.1207/s15430421tip4102_2)
