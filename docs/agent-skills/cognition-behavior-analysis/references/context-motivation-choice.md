# 情境、动机与选择

以下是产品理解方法的简明用法。需要更准确的理论定义时，查对应作者原文；方法的适用性不证明关于某个用户的解释成立。

## 情境解释与认知表征

适合解释同样任务下的不同反应，或本人如何看待问题。借鉴 CAPS 的情境性视角，查本人如何定义成功、预期后果、看待可行机会，以及这些判断出现的背景。

把“本人相信 X”“模型推测本人相信 X”“X 已被客观验证”分开。比较不同情境时看约束、角色与本人解释，不把工作交付要求直接推广为生活中的稳定偏好。

可形成有范围的 belief、assumption、frame 等认知及其对选择的影响；无必要时不另建抽象心理标签。[原始参考](https://pubmed.ncbi.nlm.nih.gov/7740090/)

## 动机与目标

适合解释为什么值得做、目标之间的联系与取舍。借鉴自我决定理论，查兴趣、本人认同、责任与外界压力如何参与；它们可以并存。有关多项活动的意义，可补读本人说明的项目关系。

区分目标与手段：“恢复精力”是本次想达到的状态，“出游”是可能手段。不要仅凭选择一种手段，就断言某种基本需要或长期价值。语义相似的目标只有在身份、时间与含义一致时才复用。

可形成 goal、有关认知及其影响决策的关系。动机与背景的联系若由模型推测，保留竞争解释。[原始参考](https://selfdeterminationtheory.org/SDT/documents/2000_RyanDeci_SDT.pdf)

## 选择与策略

适合解释为何采用一种方案，或为何仍未决定。借鉴情境化期望—价值视角，找本人实际考虑的选项、预期收益、可能性、成本和放弃其他机会的代价。信息、时间和搜索范围有限时，按当时条件理解取舍。

助手后来提出的备选方案不能补写成用户当时考虑过的方案。收益预期与成本预期可以同时成立；这种权衡不等于两项事实互相反驳。

可形成 decision、预期类 claim，以及选项受到何种影响的关系。单次策略如“先试一下”可以保留，本次使用不自动证明跨场景偏好。[原始参考](https://www.sciencedirect.com/science/article/pii/S0361476X20300242)
