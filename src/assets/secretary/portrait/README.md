# 秘书框内立绘 v3

框内单独使用三张状态立绘和一张招手立绘，均为哑光插画。人物沿用选定的小巧秘书造型，发色改为暖灰米金，减弱头发和衣物的硬反光，保留布料、皮革和柔和手绘笔触。

| 状态 | 文件 | 动作 |
|---|---|---|
| ready | idle_breathe.png | 安静抱着笔记本 |
| thinking | thinking.png | 手抵下巴，抬眼思考 |
| presenting | offering.png | 抱着笔记本递出便笺 |
| notice | wave_small.png | 抬手示意，运行时单独摆动手腕 |

四个文件均为 1024 × 1536 的白底 RGB PNG，由内置 image_gen 生成。生成器的透明底尝试实际返回了画在图中的棋盘格，未被采用。最终白底通过框内窗口的 `mix-blend-mode: multiply` 融入画框纸色；它们只用于框内，不作为透明桌宠素材。正式 PNG 没有经过脚本抠图、滤镜或重画。

`PetArtwork` 按 `variant` 选择框内或桌宠素材。框内沿用原来的 85% 窗口、底部贴边和 205% 图像高度，裁成半身；不再叠加之前补偿亮度的滤镜。常驻时有轻微呼吸，以可见腰部为变换中心，保持底部贴边，不轮换成桌宠素材。拖回时立即使用对应的框内立绘，并保留画框的短淡入，避免先出现旧桌宠质感。

桌面继续使用 `../pet/` 的原有 36 张 RGBA 素材，原有图片和桌宠缩放保持不变；日常动作补充了 `pet/daily/` 中的四张坐姿素材。两种呈现保持相同的角色身份。

生成提示词、制作过程及实际采用文件见 [source.json](./source.json)，尺寸与哈希见 [manifest.json](./manifest.json)。生成候选和临时预览属于本机制作记录，不随生产素材发布。

2026-09-06 的招手提示词同样保留在 [source.json](./source.json)；日常坐姿素材记录见 [daily/source.json](../pet/daily/source.json)。
