# 窗边肖像 · v1

用于左侧秘书形象框的一体插画。人物与淡彩窗景已合成，文件为不透明 RGB PNG，**不是透明人物层**。保持原人物的灰金发色、服装、笔记本和各动作语义，不叠加暖黄滤镜、白底混合模式或整幅缩放呼吸。

`thinking`、`offering`、`wave_small` 为约 4:5 的半身构图。`idle_breathe` 采用动作正确的 1024 × 1536 全身原图，在形象框中通过 CSS 固定取半身；人物状态之间保持接近的面部尺度。未采用的全身备选只保留在本机制作记录中，不参与运行时加载。

| 文件 | 动作 |
| --- | --- |
| `idle_breathe.png` | 安静抱着笔记本 |
| `thinking.png` | 手指轻触下巴，思考 |
| `offering.png` | 递出空白纸签 |
| `wave_small.png` | 轻轻招手 |

## 来源与生成方式

- 方式：内置 `image_gen`，2026-09-09；没有调用 API/CLI，也没有使用脚本改图。
- 人物引用：父目录同名原始 PNG。
- 背景引用：本目录 `window-background.png`。
- 构图与画风引用：制作过程中认可的「窗边一角」概念草案；草案未随仓库发布。采用的窗景与构图可查看本目录 [背景](./window-background.png) 和 [待机肖像](./idle_breathe.png)。
- `manifest.json` 记录实际采用 PNG 的尺寸、格式、哈希和取景方式。

最初尝试单独去白底，但生成结果没有实际 alpha，因此未采用这些透明提取结果。这里明确采用人物与场景一体合成的方案。

## 最终提示词要点

四态各发一个 compositing 请求：以原始同名人物图锁定脸、发型、色彩和动作，以 `window-background.png` 锁定淡蓝窗景与枝叶，以认可草案右图锁定半身构图。输出只有 4:5 竖版肖像，无边框、文字或 UI。头顶位于画面约 8%，脸位于中上部，手和笔记本完整可见，腰部以下裁掉；背景贯穿整张画面，窗棂、左上枝叶、右下书本保持相近位置。保留自然人物色彩，禁止整图黄色滤镜、白色矩形底和轮廓光晕。

idle 的半身候选误绘为挥手，后续单独修正生成等待过久，未采用。最终使用先前已生成、抱着笔记本的完整人物图，通过 CSS 取半身，没有进行脚本改图。

## QA

逐张查看过最终构图，确认背景无白色拼接矩形、人物无整图黄色滤镜，动作与状态相符。素材是生成式合成，四态背景细节相近但不是像素级相同；状态切换应保持固定大小与位置，不为背景添加运动。
