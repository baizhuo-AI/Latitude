# 逐帧动作

13 组动作，每组八张 384 × 416 RGBA PNG；`sequence.json` 保存每帧停留时间和循环节奏。

从已生成并检查的完整动作图直接裁帧，使用共同尺寸和脚部/凳子位置，保持关节与道具连接。由 `PetActionAnimation` 按整帧播放。

全部动作以用户确认的待机为人物基准，统一圆润短发、脸型、头部大小和手绘质感；坐姿按头部大小等比缩放，固定脚底与凳子位置。

每个动作目录的 `source.json` 保留来源说明、完整提示词与制作方法，`sequence.json` 保留播放节奏；例如 [待机来源](./idle/source.json) 与 [关怀动作来源](./care/source.json)。生成整张八帧动作图后，按共同尺度和脚底基线裁帧，再检查人物身份、肢体连接与循环连续性。中间图和本机检查报告不作为生产依赖。待机 PNG 与播放时序保持原样，其余 12 组重新生成。
