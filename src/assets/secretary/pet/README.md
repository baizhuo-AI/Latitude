# 桌宠动作素材 v2

这套素材以用户在 2026-09-04 选定的角色图为唯一造型基准，共 36 张独立动作。角色保持暖灰金短发、灰绿眼、黄绿菱形发夹、炭黑短外套与短披肩、奶油色短裙、暖棕丝袜、蝴蝶结圆头鞋和深棕笔记本；身材小巧纤细，头部比例按选定图收小。

本目录用于拖出后的透明桌宠，保持用户满意的现有质感。框内改用 [portrait](../portrait/README.md) 中同一角色的三张独立哑光立绘，保留暖纸画框、椭圆虚线、状态签、85% 半身窗口和底部贴边。按住拖出后使用本目录的完整人物；拖回时立即换回框内立绘，并恢复画框。桌面上的 35 张素材使用 `scale: .75`；`walk_right` 的原图留白较多，单独使用 `.82`。桌宠有效人物高度为画布的 67.82%–72.46%，与选定图约 70% 的比例一致。

## 使用原则

在岗整理和有结果待看时，先保持当前语义姿势 6 秒，然后低频轮换呼吸、短暂眨眼、左右看、整理头发与伸懒腰；有待看结果不会再把角色永久锁在提醒图片上。思考、倾听和拖动会暂停休息姿势，工作动作仍跟随真实任务状态。所有常驻姿势都有轻微呼吸或思考摆动；不会把全部表情随机轮播。

提醒按用户设置演一次或循环。单次动作结束后恢复常驻动作，即使气泡被设置为持续保留。系统开启“减少动态效果”时，停用持续动效和休息姿势轮换。`walk_left`、`walk_right`、`speaking_happy`、`typing`、`confused`、`apologetic`、`pout` 等作为明确场景或后续扩展素材保留；本次没有增加自动走动。

每张图都是 `1024 × 1536` 真 RGBA PNG。alpha、尺寸和人物包围盒记录在 [manifest.json](./manifest.json)。制作时使用三种底色检查透明边缘和人物比例；临时总览与旧版备选属于本机制作记录，不作为运行时依赖。

## 生成与验收

素材由内置 `image_gen` 逐张生成或编辑。背景透明化仍由同一工具完成；没有对正式人物图使用脚本抠图、色键或重画。脚本只负责复制文件、读取尺寸与 alpha、生成清单和 QA 预览。

验收门槛：完整人物不裁切；角色造型与选定图一致；RGBA 且存在 alpha=0；按最终显示比例，人物有效高度约为画布的 68%–72%；在浅色、深色和高饱和绿色背景上没有棋盘格、纸底、明显绿边或大面积光晕。36 张正式素材全部通过；早期有光晕的庆祝动作留在 QA 记录中，没有进入正式目录。
